# Engineering Contract Router

When the task changes business semantics, schemas, persistence semantics, scoring, selection, routing, state transitions, validators, gates, or externally visible result behavior:

1. Read `ENGINEERING_CONTRACT.md` from the workspace root.
2. Use `contract-impact-check` before editing.
3. Preserve immutable evidence and test integrity.

For typo-only, cosmetic, or clearly local non-semantic edits, do not load the full contract unnecessarily.

Recommended Antigravity IDE activation:

```text
Model Decision
```
