# Stage Prompt Example
Role: Builder
Stage Goal: obtain one verifiable runnable outcome.
Scope: only necessary files.
Write Allowlist: explicit.
Forbidden: destructive/unrelated/Git writes without authorization.
Validation: Unit + Real Path + Runtime as applicable.
Required Evidence: baseline/diff/tests/runtime/Git status.
Exit: implementation complete for independent review.
Stop: blocking safety/data-loss/core-path conditions.
