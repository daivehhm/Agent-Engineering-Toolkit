# Future Candidates
These are not current roadmap commitments. Every item requires trigger evidence.

## Automated Command Capture
Trigger: repeated cross-project provenance gaps where manual Critical Command Evidence is consistently missing/unreliable.

## Evaluation Aggregation
Trigger: enough real `stage_outcome.json` data across projects/Agents. First implementation should be a simple offline aggregator.

## MCP Adapter
Trigger: multiple independent clients repeatedly need the same executable AET capability and native Skill/file adapters create measurable duplication.

## CI Adapter
Trigger: repeated manual CI evidence ingestion creates meaningful review cost. CI remains Evidence Source, not final Review Authority.

## Enterprise Policy Integration
Trigger: real enterprise adoption requires identity/RBAC/retention/compliance integration.

No trigger evidence => no Agent Manager, centralized lock server, Receipt DB, Dashboard, Policy Engine, Vector DB, or model leaderboard.
